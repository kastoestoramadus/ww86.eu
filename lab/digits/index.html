Letter sums and digit roots

Splits a name into vowels and consonants, adds up their letter values, reduces each sum to a single digit and counts how many letters carry each digit. The arithmetic is a pure Scala module, cross-compiled to the browser.

How it works

Each letter carries a digit from the 1-9 cycle, with Polish diacritics folded onto their base letter. Vowels and consonants are summed separately, then each sum is reduced by repeated digit sum until one digit is left.

The second table counts the letters that carry each digit, word by word and for the whole name; a 0 marks a digit that no letter carries.

The arithmetic lives in a cross-compiled module, so the same code and the same tests run on the JVM and in the browser. It carries no interpretation of the numbers: what a sum is supposed to mean is the caller's business, not the calculator's.

Built with Scala 3, Scala.js, Laminar.
