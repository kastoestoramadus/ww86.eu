Letter sums and digit roots

Splits a name into vowels and consonants, adds up their letter values, reduces each sum to a single digit and counts how many letters carry each digit. It can also find a first name from the PESEL register that gives a name the wanted roots. The arithmetic is a pure Scala module, cross-compiled to the browser.
